# Journal de sessions

## Règles
- Une entrée courte à la fin de chaque session utile ou après une action externe.
- Écrire ce qui a été décidé et fait, pas la totalité de la conversation.
- Pour chaque action sensible, indiquer la preuve, la date et la prochaine relance.

## Format
```text
### AAAA-MM-JJ — Dossier
- Demande :
- Faits / sources ajoutés :
- Décision :
- Action réalisée :
- Preuve / lien interne :
- Prochaine action :
- Échéance ou date de relance :
- Statut : ouvert / en attente / clos / parking
```
