# Index des dossiers

## Mode d’emploi
Une ligne par dossier actif. Le détail factuel, la chronologie, les sources et les décisions peuvent être ajoutés dans un sous-dossier ou une note dédiée lorsque nécessaire. Ce fichier reste l’écran de pilotage : peu de texte, des états exacts, une prochaine action datée.

## Principes de classement
- Un dossier est P0 si un délai, une perte ou un risque irréversible exige une action immédiate.
- Un dossier est P1 si une action datée dans les 7 jours a un impact élevé ou débloque une situation.
- Un dossier est P2 s’il mérite une planification mais sans dommage immédiat.
- Un dossier est P3 s’il doit être préservé sans être alimenté maintenant.
- Tout changement de priorité doit être justifié par une date, une nouvelle source, une réponse reçue ou un recalcul de la matrice.
