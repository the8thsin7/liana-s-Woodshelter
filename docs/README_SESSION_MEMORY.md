### Storage logic

- Structured documentation and Markdown: GitHub first.
- Working documents, office files, exports and reference material: Google Drive.

When a new item is validated in a session, prepare it for archival in the appropriate connected location. Any external write, update, creation, move, deletion, publication, or share action requires confirmation at the time of execution.
